# SQL Essencial

Nesta pasta encontram-se os materiais e os scripts desenvolvidos durante o estudo de SQL essencial.

## Documentação da Semana 09

Na pasta `04_sql_essencial` também está disponível o documento Word `SQL_Essencial_TechStore.docx`, que contém as instruções, explicações e atividades trabalhadas nas aulas da Semana 09.

## Scripts SQL por tipo de comando

Os arquivos abaixo foram organizados conforme o tipo de comando SQL:

- `Comandos DDL.sql` — comandos de Definição de Dados, como `CREATE`, `ALTER`, `DROP`.
- `Comandos DML.sql` — comandos de Manipulação de Dados, como `INSERT`, `UPDATE`, `DELETE`.
- `Comandos DQL.sql` — comandos de Consulta de Dados, como `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, `JOIN` e filtros.

Esses scripts servem como material de apoio para praticar os conceitos de estrutura, manipulação e consulta de banco de dados em SQL.
